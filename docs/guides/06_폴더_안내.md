# 불새 폴더 안내

프로젝트 루트에서 작업합니다. 실행 명령은 [Streamlit 실행 가이드](05_Streamlit_실행_배포.md), 코드별 설명은 [프로젝트 파일 안내](../../00_파일_안내.md)를 참고하세요.

| 위치 | 역할 |
|---|---|
| `src/bulsae/` | 불새 서비스의 Python 코드. `graphrag/`에 검색, 답변 생성, 화면 코드가 있습니다. |
| `tests/` | 외부 API와 DB를 직접 호출하지 않는 자동 테스트와 별도 실시간 검증 스크립트가 있습니다. |
| `data/collected/` | 수집한 기업 정보, 재무 및 뉴스 데이터입니다. |
| `data/processed/` | 가공한 뉴스 청크 등입니다. |
| `data/raw/` | 원본 자료를 위한 위치입니다. |
| `data_code/` | 수집·실험 노트북과 기업별 수집 체크포인트입니다. 노트북의 상대 경로를 유지하기 위해 기존 위치에 둡니다. |
| `docs/guides/` | 프로젝트 이해, 개발, 검증, 실행 및 폴더 안내입니다. |
| `private_data/` | 원문과 실행 기록이 포함될 수 있는 로컬 자료입니다. 공개하지 않습니다. |
| `connect-ui/` | 기존 정적 웹 화면과 사용법입니다. 기존 웹 서버가 참조합니다. |
| `baik/` | 별도 Python 패키지와 팀원 작업 기록입니다. 프로젝트 설정과 Docker 빌드에서 참조합니다. |

## 로컬 기록

| 위치 | 역할 |
|---|---|
| `private_data/query_runs/` | 서비스가 저장하는 질의별 실행 기록. 서비스가 직접 사용하는 경로입니다. |
| `private_data/checkpoints/` | 전체 기사 처리 체크포인트와 파일럿 실행 기록입니다. |
| `private_data/evaluations/` | 골든셋, 서비스 통합, 관계 및 식별 검토 기록입니다. |
| `private_data/experiments/` | 기능별 실험, 디버깅, 점검 결과입니다. |
| `private_data/ui_previews/` | 화면 시안과 배포 확인 캡처입니다. |
| `private_data/backups/` | 작업 전 보관한 사본입니다. |

이 폴더의 기록은 Git에서 제외되므로 별도 백업이 필요합니다. `query_runs/` 외의 새 폴더도 기록을 정리하기 위한 로컬 위치이며, 팀원에게 자동으로 공유되지는 않습니다.

## 루트 설정 파일

`streamlit_app.py`는 서비스 진입점이며, `pyproject.toml`과 `uv.lock`은 Python 환경을 정의합니다. `Dockerfile.streamlit`과 `.streamlit/`은 실행·배포 설정입니다. `.env`는 접속 비밀값, `.venv/`는 로컬 Python 환경, `.git/`은 Git 이력입니다. 이 파일과 폴더는 임의로 옮기지 않습니다.
