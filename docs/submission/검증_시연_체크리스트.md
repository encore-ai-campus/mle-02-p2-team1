# 검증과 시연 준비

아래는 작성용 체크리스트입니다. 미확인 항목을 완료된 것으로 표시하거나 예시를 실제 결과로 제시하지 않습니다.

## 대표 사례 한 건

| 단계 | 기록할 내용 | 상태 |
|---|---|---|
| 문서 선정 | 문서명, 출처, 선정 이유, 공유 범위 | 미정 |
| 전처리 | 문서 ID, 분할 기준, 원문 위치와 전후 예시 | 미정 |
| 추출 | 실제 프롬프트·모델, 개체와 주어–관계–목적어, 근거 | 미정 |
| 정규화 | 원문 표기, 대표 ID, 동일 또는 별개 판단 근거 | 미정 |
| Neo4j 적재 | 실제 데이터셋, 노드·관계 유형, 출처 속성 | 미정 |
| 조회·시각화 | 실행한 Cypher, 결과 화면, 해석 | 미정 |
| 검증 | 원문·관계 방향·정규화·적재 결과의 대조 및 조치 | 미정 |

문서 기반 추출은 문서 본문의 줄과 문자 위치를 사용합니다. 시연 경로가 청크 기반인지 문서 기반인지 명시하고 실제 사용한 ID와 위치만 기록합니다.

## 검증 기록에 포함할 것

- 대상 자료, 선정 기준과 검토 건수. 임의 선정과 무작위 표본을 구분합니다.
- 원문과 추출 결과의 주어·관계·목적어, 방향과 근거 비교.
- 동일 개체의 통합과 다른 개체의 오병합 여부, 전후 사례.
- 스키마 허용 유형·관계와 적재 시 누락·중복·출처 유지 여부.
- 오류의 원인, 조치, 수정 후 재확인 결과와 남은 한계.
- 정확도 등 수치를 제시한다면 정답 기준·표본 수·계산 방법. 정답 라벨 없이 성공률을 만들지 않습니다.

[M8 완료 보고서](../../baik/new/M8_completion_report.md)는 특정 팀원 데이터셋에 대한 선정 사례와 행사 오병합 보완 기록입니다. 전체 그래프의 정확도나 현재 상태를 보증하는 자료가 아닙니다.

## 팀 회고 KPT

팀원이 실제 경험을 바탕으로 작성합니다.

| 구분 | 기록할 내용 |
|---|---|
| Keep | 잘 작동해서 다음에도 유지할 방식 |
| Problem | 막힌 점과 그 영향, 해결하지 못한 한계 |
| Try | 다음에 시도할 구체적인 개선과 담당 |

개인별 기여, 막힌 지점, 시도한 해결 방법과 선택 이유를 함께 기록합니다.
