> 시범 사례: 아모레퍼시픽 관련 7개 기업

## 1. 단계 결과 한눈에 보기

- 기존 스키마 초안을 **M0의 CQ 10개**와 추가 공시의 지분 관계에 맞춰 점검했다.
- **개체 유형 12개와 서술어 12개**의 의미·방향·허용 유형을 정리했다.
- 공시의 **지분율, 기준일, 비율 기준, 원문 주석과 출처**를 보존하는 규칙을 보완했다.
- 사용자 결정에 맞춰 **주장 노드 없이 개체 간 직접 관계**를 기본 모델로 정리했다.
- 스키마상 경로가 가능한지와 현재 데이터에 경로 후보가 있는지를 나눠 확인했다.
- 상세 결과는 [M2_schema_and_connection_rules.md](M2_schema_and_connection_rules.md)에 정리했다. GitHub에는 두 파일을 **같은 폴더**에 올린다.

> M2의 완료는 스키마 설계와 연결 규칙을 정리했다는 의미다. 모든 CQ에 실제로 답할 수 있다거나 모든 추출 결과가 검증됐다는 의미는 아니다.

## 2. M2의 목적과 범위

기업 조사 질문을 그래프로 표현하기 위해 **개체 유형, 서술어, 속성, 서술어의 방향 및 연결 가능 유형**을 정의한다. 이번 점검에는 기존 M2 초안, M0 CQ 10개, 4개 JSONL의 추출 결과, 추가 공시의 지분 관계를 사용했다.

대상은 아모레퍼시픽 관련 7개 기업과 필요한 주변 기업·브랜드·제품·인물·행사 등이다. 이 기업들은 여러 산업에 적용할 기업 조사 방식의 시범 대상이다.

## 3. 개체 유형 정의 결과

**개체**는 그래프에서 따로 구분해 표현하려는 대상이다. 그래프에서는 보통 각각을 **노드**로 나타낸다. 예를 들어 회사와 브랜드는 이름이 같아도 서로 다른 개체다.

| 개체 유형 | 쉽게 설명하면 | 예시 |
| --- | --- | --- |
| `Company` · 회사 | 사업을 하는 **법인 회사**. 기업의 지분이나 재무정보를 연결할 때 사용 | 주식회사 아모레퍼시픽, 주식회사 이니스프리 |
| `CorporateGroup` · 기업집단 | 여러 회사를 포괄해 부르는 **기업들의 집단**. 한 회사인 지주회사와 구분 | 아모레퍼시픽 기업집단 |
| `Organization` · 기관·단체 | 기업 외의 정부기관, 연구기관, 협회 등 단체 | 식품의약품안전처 같은 정부기관 |
| `Person` · 인물 | 기업과 관련된 임직원, 주주 등 실제 사람 | 기사에서 아모레퍼시픽 임원으로 소개된 박원석 |
| `Character` · 캐릭터 | 행사나 제품 홍보에 등장하는 가상의 캐릭터. 실제 사람과 구분 | 망그러진 곰 |
| `Brand` · 브랜드 | 소비자가 제품이나 서비스를 구분할 때 사용하는 이름. 회사를 뜻하는 경우와 구별 | 이니스프리 브랜드 |
| `Product` · 제품 | 회사나 브랜드가 판매·소개하는 개별 상품 | 에이피 뷰티의 듀얼 리페어 리프트 M.D. 크림 미스트 |
| `Market` · 시장 | 기업이 활동하는 국가별·제품별 시장 | 한국 화장품 시장과 같이 범위를 정한 시장 |
| `Event` · 행사·사건 | 행사, 제품 발표, 협업 등 특정 시점에 일어난 활동이나 사건 | 2026 국회 입법박람회 |
| `Place` · 장소 | 국가, 도시 또는 행사가 열린 공간 | 국회 중앙잔디광장 |
| `MetricObservation` · 지표 관측값 | 매출액처럼 **어떤 대상의 수치**를 기간·단위와 함께 담는 개체 | 아모레퍼시픽의 2025년 매출액 기록 |
| `Regulation` · 규정·법령 | 기업·제품·시장에 적용되는 법령이나 규정 | 화장품에 적용되는 규정 |

총 **12개 추출 유형**이다. 위 표는 유형의 이해를 돕기 위한 예시이며, 모든 예시가 검증되어 적재된 결과라는 뜻은 아니다. `Document`와 `Chunk`는 각각 문서와 문서에서 나눈 구간을 뜻하는 출처 기록으로, M4에서 개체로 추출하는 12개 유형에는 포함하지 않는다.

## 4. 서술어와 방향

**서술어(Predicate)**는 두 개체가 어떤 관계인지를 **‘지분을 보유한다’, ‘행사에 참여한다’처럼 설명하는 말**이다. Neo4j에서는 서술어를 관계 유형 코드로 구현한다.

> **아모레퍼시픽홀딩스** → **지분을 보유한다** → **아모레퍼시픽**
>
> 주어: 아모레퍼시픽홀딩스 · 서술어: 지분을 보유한다 · 목적어: 아모레퍼시픽

화살표는 왼쪽 개체에서 오른쪽 개체를 향한다. 영문 코드는 실행 코드에서 사용하는 이름이며, 한글은 이해를 돕기 위해 풀어 쓴 표현이다. 예시는 **방향과 뜻을 설명하기 위한 것**이며, 별도 검토 없이 모두 사실로 확정한 결과는 아니다.

| 서술어 · 코드 | 연결 방향 | 쉽게 설명하면 |
| --- | --- | --- |
| **직책을 맡는다** `HOLDS_POSITION` | 인물 → 회사·기관 | 사람이 어느 회사나 기관에서 직책을 맡았다는 뜻. 예: `인물 → 직책을 맡는다 → 아모레퍼시픽`. 직책명과 해당 시점은 근거가 있을 때 함께 기록. |
| **지분을 보유한다** `OWNS_STAKE` | 회사·인물 → 회사 | 주주인 회사 또는 사람이 다른 회사의 지분을 보유한다는 뜻. 예: `홀딩스 → 지분을 보유한다 → 아모레퍼시픽`. 지분율과 기준일도 확인. |
| **기업집단에 속한다** `PART_OF_GROUP` | 회사 → 기업집단 | 법인 회사가 어느 기업집단에 속해 있다는 뜻. 예: `회사 → 기업집단에 속한다 → 아모레퍼시픽 기업집단`. 직접 지분 보유와는 다른 정보. |
| **브랜드를 운영한다** `OPERATES_BRAND` | 회사 → 브랜드 | 회사가 브랜드를 운영한다는 뜻. 예: `회사 → 브랜드를 운영한다 → 브랜드`. 이름이 같다는 이유만으로 연결하지 않고 원문을 확인. |
| **브랜드에 속한다** `PRODUCT_UNDER_BRAND` | 제품 → 브랜드 | 개별 제품이 어느 브랜드에 속하는지 표시. 예: `크림 미스트 → 브랜드에 속한다 → 에이피 뷰티`. |
| **행사·활동에 참여한다** `PARTICIPATES_IN` | 회사·기업집단·브랜드·인물·기관 → 행사·사건 | 누가 어떤 행사나 활동에 참여했는지 표시. 예: `아모레퍼시픽 → 행사에 참여한다 → 국회 입법박람회`. |
| **지표가 기록되어 있다** `REPORTS_METRIC` | 회사·기업집단·브랜드·시장·제품 → 지표 관측값 | 어떤 대상에 관해 매출액 등 수치가 기록되어 있다는 뜻. 예: `회사 → 지표가 기록되어 있다 → 2025년 매출액`. 서술어만으로 회사가 직접 공시했다고 단정하지 않음. |
| **지역에 해당한다** `MARKET_IN_PLACE` | 시장 → 장소 | 특정 시장이 어느 국가나 지역에 해당하는지 표시. 예: `한국 화장품 시장 → 지역에 해당한다 → 대한민국`. |
| **장소에서 열렸다** `EVENT_IN_PLACE` | 행사·사건 → 장소 | 어떤 행사가 어디에서 열렸는지 표시. 예: `국회 입법박람회 → 장소에서 열렸다 → 국회 중앙잔디광장`. |
| **행사에서 소개되었다** `PRODUCT_FEATURED_IN` | 제품 → 행사·사건 | 제품이 특정 행사에서 소개되었다는 뜻. 예: `제품 → 행사에서 소개되었다 → 신제품 행사`. |
| **캐릭터가 등장한다** `EVENT_FEATURES` | 행사·사건 → 캐릭터 | 행사나 협업에 어떤 캐릭터가 등장하는지 표시. 예: `협업 행사 → 캐릭터가 등장한다 → 캐릭터`. 캐릭터의 소유권까지 뜻하지는 않음. |
| **규제 대상으로 삼는다** `REGULATES` | 규정·법령 → 제품·시장 | 법령이나 규정이 특정 제품·시장을 규제 대상으로 한다는 뜻. 예: `규정 → 규제 대상으로 삼는다 → 제품`. 제품이 규정을 위반했다는 뜻은 아님. |

총 **12개 서술어**다. 실제 연결은 허용된 유형과 방향에 맞아야 하며, 해당 내용을 뒷받침하는 원문 근거가 필요하다.

기존 M2 초안에서 신규 제안이었던 일부 유형과 서술어도 이번에 확인한 **병렬 M4 검증기에는 이미 반영**되어 있다. 다만 기존 M6 시험 로더가 12개 유형과 서술어를 모두 처리한다는 뜻은 아니다.

## 5. 공시 자료를 반영한 핵심 규칙

### 지분 관계

> 투자회사 또는 인물 → `OWNS_STAKE` → 피투자회사

관계에는 확인 가능한 범위에서 **지분율, 단위, 기준일, 지분율의 기준, 출처와 원문 근거**를 연결한다. 발행일과 지분 기준일, 보고서 표의 결산일은 서로 구분한다.

| 공시 사례 | M2에 반영한 규칙 |
| --- | --- |
| 홀딩스 → 아모레퍼시픽 38.1% | 과반 미만에도 사실상 지배력이 있다는 보고서 주석을 함께 보존 |
| 홀딩스 → 이니스프리 90.4% | 자기주식을 제외한 실질지분율 관련 주석을 함께 보존 |
| 2025-12-31과 2026-03-31 관측 | 같은 회사 쌍이라도 기준일이 다른 관측을 구분 |
| 퍼시픽테크의 기사·공시 표현 차이 | 원문·시점을 검토하기 전 상충 가능 관계를 자동 병합하지 않음 |

### 직접 관계와 출처

사용자의 요청에 따라 기본 그래프는 다음과 같이 설계한다.

> 회사 → **지분 보유** → 회사  
> 관계 정보: 지분율 · 기준일 · 출처 · 원문 근거

주장 노드를 기본 모델에 추가하지 않고, **여러 출처를 관계 속성에 보존하는 방식**을 제안했다. 다만 복수 근거의 실제 저장 형식과 동일 관계·다른 시점의 적재 키는 M6에서 구현하고 시험해야 한다.

## 6. CQ 대조 결과

| CQ | 스키마 표현 | 현재 확인 결과 |
| --- | --- | --- |
| CQ01 기업 기본정보 | 가능 | 7개 회사의 구조화 정보 후보 있음. 필드별 출처 확인 필요 |
| CQ02 2025 재무정보 | 가능 | 14개 재무 지표 후보. 공시 원문·단위·범위 확인 필요 |
| CQ03 홀딩스 직접 지분 | 가능 | 2026-03-31 공시의 6개 대상 기업 행 후보 있음 |
| CQ04 홀딩스 → 아모레퍼시픽 → 코스알엑스 | 가능 · 2홉 | 두 지분 관계의 공시 후보 있음. 적재 및 ID 연결 필요 |
| CQ05 인물·직책 | 가능 | 기사 관계 후보 있음. 직책·시점·근거 검토 필요 |
| CQ06 지분 → 기업 → 브랜드 → 제품 | 가능 · 3홉 | 공시와 기사 후보를 연결하면 구조적 경로 후보 있음 |
| CQ07 지분 → 기업 → 행사 → 장소 | 가능 · 3홉 | 구조적 경로 후보 있음. 각 관계의 시점 확인 필요 |
| CQ08 인물 → 기업 → 브랜드 → 제품 | 가능 · 3홉 | 구조적 경로 후보 있음. 직책과 다른 관계의 시점 확인 필요 |
| CQ09 홀딩스 → 아모레퍼시픽 → 코스알엑스 → 브랜드 → 제품 | 가능 · 4홉 | **현 후보에서 대표 회사 ID 기준 경로 미확인** |
| CQ10 인물 → 회사 → 기업 → 브랜드 → 행사 → 장소 | 가능 · 5홉 | **지정한 관계 순서의 경로 미확인** |

경로 후보 확인에는 기존 M5 중 양쪽 개체가 자동 연결 또는 잠정 연결된 뉴스 관계, 구조화 관계 및 추가 공시 후보를 사용했다. 날짜 필터와 원문 의미를 일괄 검증하지 않았으므로 **경로가 있다는 것만으로 정답이 검증된 것은 아니다.** 미결 개체는 이 점검에서 제외했으며, 회사 ID와 브랜드 ID를 이름만으로 합치지 않았다.

CQ09와 CQ10은 경로를 억지로 만들지 않고 기존 추출 결과·동일 법인 후보·질문의 실용성을 다음 단계에서 확인한다. 현재 데이터로 답하기 어렵다면 질문 수정 또는 시연 범위 조정이 필요하다.
