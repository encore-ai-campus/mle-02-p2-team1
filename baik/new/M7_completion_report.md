## 2. M7의 목적과 조회 범위

M7의 목적은 AuraDB에 적재된 그래프를 **Cypher로 조회하고, 기업·인물·브랜드·행사 사이의 연결을 화면으로 확인**하는 것이다. 이때 M0의 역량 질문(CQ)을 조회 기준으로 사용한다.

이번 조회는 `B_M6Entity`와 `dataset_id = 'brian_m6_20261108_v1'`을 기준으로 하여, 같은 AuraDB를 쓰는 다른 팀원의 데이터와 구분했다. 관계 역시 같은 데이터셋에 속한 것만 대상으로 삼았다.

**홉(hop)**은 경로에서 지나가는 관계의 수다. 예를 들어 `A → B → C`는 관계가 두 개이므로 **2홉**이다. 관계의 화살표는 실제 저장 방향을 뜻하며, 조회 경로에서는 화살표 반대 방향으로 관계를 따라갈 수도 있다.

홀딩스와 아모레퍼시픽 사이의 선은 두 개다. 사용자가 관계 속성을 CSV로 조회한 결과, 두 선은 모두 38.1%이지만 **공시 관측 기준일이 서로 달랐다.**

| 지분 관계 | 지분율 | 공시 기준일 |
| --- | ---: | --- |
| 홀딩스 → 아모레퍼시픽 | 38.1% | **2025-12-31** |

같은 수치라도 기준일이 다른 기록이므로 단순 중복으로 지우지 않았다. 브랜드·제품 관계는 기사에서 추출된 잠정 결과이므로 원문과 시점을 별도로 대조해야 한다.

### 5.3 서경배에서 행사 장소까지 · 5홉

![서경배부터 이니스프리 팝업 장소까지의 5홉 연결](images/m7_5hop.svg)

**경로:** 서경배 → 아모레퍼시픽홀딩스 → 이니스프리 회사 → 이니스프리 브랜드 → 팝업스토어 → 이니스프리 디아일 성수

회사와 브랜드는 이름이 같아도 서로 다른 노드다. 이미지에 지분 관계선이 여러 개 보이므로 사용자가 해당 두 구간의 관계 속성을 추가 조회했다.

| 조회한 구간 | 저장된 관계 기록 | 확인된 내용 |
| --- | ---: | --- |
| 서경배 → 아모레퍼시픽홀딩스 | 7개 | 기사별로 50.28%, 54.97%, 56% 이상, 56.39%, 57.12%, 종류주 11.65% 등의 표현. 57.12%는 서로 다른 속성으로 두 관계가 있음 |
| 아모레퍼시픽홀딩스 → 이니스프리 | 2개 | 두 관계 모두 수치와 기준일은 비어 있으며, 한 관계의 원래 표현은 `지분 대부분` |

이 구간에서 조회한 **9개 관계가 모두 SVG에 각각 표시된 것은 아닐 수 있다.** 시각화는 경로 조회의 반환 범위와 화면 표시 설정에 영향을 받는다. 7개 인물 지분 관계의 `as_of_date`는 모두 비어 있으며, 기사 발행일을 지분 기준일로 대체하지 않았다. `56% 이상`은 정확히 56%라는 의미가 아니고, **보통주와 종류주 지분은 같은 기준으로 바로 비교할 수 없다.**

첫 5홉 표본의 근거에는 2024년·2025년·2026년에 발행된 기사가 섞여 있다. 이는 연결을 구성하는 각각의 기사 발행일일 뿐 관계가 동시에 성립한 기준일을 보장하지 않는다. 여러 선을 임의로 합치거나 최신 수치 하나를 결정하지 않았으며, M8에서 각 관계의 원문·기준일·개체 동일성을 검토한다.

## 6. 사용한 Cypher와 실행 자료

### 6.1 노드와 관계 유형 조회

```cypher
MATCH (n:B_M6Entity {dataset_id: 'brian_m6_20261108_v1'})
RETURN n.entity_type AS node_type, count(n) AS node_count
ORDER BY node_count DESC, node_type;
```

```cypher
MATCH (a:B_M6Entity {dataset_id: 'brian_m6_20261108_v1'})-[r]->
      (b:B_M6Entity {dataset_id: 'brian_m6_20261108_v1'})
WHERE r.dataset_id = 'brian_m6_20261108_v1'
RETURN type(r) AS relationship_type,
       count(r) AS relationship_count,
       sum(coalesce(r.source_count, 0)) AS source_record_count
ORDER BY relationship_count DESC, relationship_type;
```

### 6.2 고립 노드 확인

```cypher
MATCH (n:B_M6Entity {dataset_id: 'brian_m6_20261108_v1'})
WHERE NOT EXISTS {
  MATCH (n)-[r]-(m:B_M6Entity {dataset_id: 'brian_m6_20261108_v1'})
  WHERE r.dataset_id = 'brian_m6_20261108_v1'
}
RETURN count(n) AS isolated_node_count;
```

조회 결과는 **0**이었다. 처음 전체 데이터 화면에서 보였던 다른 팀원의 데이터는 이 확인 범위에서 제외했다.

### 6.3 대표 시각화 Cypher

아래 세 쿼리는 사용자가 실행한 대표 경로 쿼리다. `RETURN path`는 경로의 노드와 관계를 함께 반환한다.

#### 2홉: 공시 지분 관계

```cypher
MATCH path = (holding:B_Company {entity_id:'COMPANY-AMOREPACIFIC-HOLDINGS'})
             -[r1:B_OWNS_STAKE]->
             (amore:B_Company {entity_id:'COMPANY-AMOREPACIFIC'})
             -[r2:B_OWNS_STAKE]->
             (cosrx:B_Company {entity_id:'COMPANY-COSRX'})
WHERE all(n IN nodes(path) WHERE n.dataset_id = 'brian_m6_20261108_v1')
  AND all(r IN relationships(path) WHERE r.dataset_id = 'brian_m6_20261108_v1')
  AND r1.as_of_date = '2026-03-31'
  AND r2.as_of_date = '2026-03-31'
  AND coalesce(r1.status, '') <> 'planned'
  AND coalesce(r2.status, '') <> 'planned'
RETURN path
LIMIT 10;
```

#### 3홉: 기업·브랜드·제품

```cypher
MATCH path = (holding:B_Company {entity_id:'COMPANY-AMOREPACIFIC-HOLDINGS'})
             -[:B_OWNS_STAKE]->
             (amore:B_Company {entity_id:'COMPANY-AMOREPACIFIC'})
             -[:B_OPERATES_BRAND]->
             (brand:B_Brand {entity_id:'AUTO-0844f77d5fe95dfe45512c54'})
             <-[:B_PRODUCT_UNDER_BRAND]-
             (product:B_Product {entity_id:'PRODUCT-RULE-58c33d0e6bf0e5ae9f30'})
WHERE all(n IN nodes(path) WHERE n.dataset_id = 'brian_m6_20261108_v1')
  AND all(r IN relationships(path) WHERE r.dataset_id = 'brian_m6_20261108_v1')
RETURN path
LIMIT 10;
```

이 경로는 1차 조회 표본에서 나온 한율·제품 예시다. 화살표 방향은 **제품→브랜드**이므로 홀딩스에서 제품을 따라가며 볼 때 마지막 화살표를 거꾸로 탐색한다. 서로 다른 시점의 공시·기사 관계가 섞일 수 있다.

#### 5홉: 인물에서 행사 장소까지

```cypher
MATCH path = (person:B_Person {entity_id:'PERSON-RULE-f6a2566b625c55579d14'})
             -[:B_OWNS_STAKE]->
             (holding:B_Company {entity_id:'AUTO-35e7396534ca88cbf4b974da'})
             -[:B_OWNS_STAKE]->
             (company:B_Company {entity_id:'AUTO-3d295451c1408042c9ad79cb'})
             -[:B_OPERATES_BRAND]->
             (brand:B_Brand {entity_id:'BRAND-INNISFREE'})
             -[:B_PARTICIPATES_IN]->
             (event:B_Event {entity_id:'EVENT-LOCAL-41d4094c93bfe76a380c'})
             -[:B_EVENT_IN_PLACE]->
             (place:B_Place {entity_id:'AUTO-02d895f9363095da99ca24d0'})
WHERE all(n IN nodes(path) WHERE n.dataset_id = 'brian_m6_20261108_v1')
  AND all(r IN relationships(path) WHERE r.dataset_id = 'brian_m6_20261108_v1')
RETURN path
LIMIT 10;
```

이 경로에는 잠정 정규화된 인물·회사와 시점이 다른 기사들이 포함된다. **5홉 조회가 가능하다는 시각화 사례**로 사용하고, 사실·기간 검토 전에는 확정 답변으로 제시하지 않는다.
