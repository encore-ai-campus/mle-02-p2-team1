# M8 뉴스·M7 경로 표본 검증 메모

> 검증 자료의 수집 시점과 사용자 제공 AuraDB 조회 스냅샷을 기준으로 작성한 작업 메모. 현재 AuraDB를 다시 조회하거나 수정하지 않았다.

## 1. 선정 범위와 확인 기준

- **M7 경로 표본 16개:** CQ02 2개, CQ04 2개, CQ05 2개, CQ06 2개, CQ07 2개, CQ08 1개, CQ10 5개. 각 항목은 M7 결과의 *서로 다른 원본 관계 기록* 한 건이며, 관계에 출처가 여러 개라면 이 검토는 선택한 원본 기록을 기준으로 한다. CQ06 제품 사례가 별도 집중 검토 사례와 겹친다.
- **추가 집중 검토 2개:** 사용자가 4.3 시각화 지분 관계 조회 CSV로 제공한 `56% 이상`과 `종류주 11.65%` 관계. 따라서 중복을 제외한 전체 대상은 **원본 관계 기록 18건**이다.
- 일부 사례는 복잡한 다중 홉과 오류 가능성을 보기 위해 의도적으로 선택했다. **무작위 표본이 아니며 전체 정확도를 대표하지 않는다.**
- 뉴스 14건은 `upload/news(1).jsonl` 수집 원문 사본의 원문 구간과 `upload/m4_output(1).zip`의 `input.primary_text`, M4 관계·속성·인용을 비교했다. 원문 사본의 `content[char_start:char_end]`는 모두 각 M4 청크와 일치했고 M4 인용 문자열도 청크 안에 있었다.
- M5는 `M5_remaining_quick_result.zip`의 `news_relations_in_scope.jsonl` 또는 `structured_disclosure_relations.jsonl`을 사용했다. M7 경로 16건은 사용자가 제공한 `m7_output.zip`의 실제 그래프 조회 당시 관계 속성 `sources_json`의 선택 원본 기록이 M5 기록과 일치하는지 대조했다. 추가 2건은 사용자가 제공한 `4.3.csv`의 그래프 관계 ID·수치·원래 표현을 비교했으며, 이 CSV 자체에는 전체 `sources_json`이 포함되어 있지 않다.
- 공시 2건은 원본 공시 HTML 사본(`ownership_disclosure_M1_M5.zip`)의 표 행 XPath와 M5 관계·M7 결과를 비교했다. 재무 2건은 팀 `financials.jsonl`과 그래프 속성을 비교하고, 한국거래소 KIND에 게시된 [아모레퍼시픽 2025년 사업보고서 원문](https://kind.krx.co.kr/external/2026/03/18/001026/20260318004903/11011.htm)의 개별 포괄손익계산서를 별도로 확인했다. DART 원래 URL 자체의 직접 접근은 확인하지 못했으나 같은 연도 사업보고서의 KIND 게시 원문과 값·단위·기간을 대조했다.
- 기사 사이트 2곳(56% 이상, 11.65%)은 재접속 시 HTTP 403이어서 수집된 원문 사본 기준으로 대조했다. 기사에 적힌 내용과 기업의 실제 최신 지분이 항상 같다는 검증은 아니다.

**중요:** 원문 문자열이 존재하고 M4·M5·그래프의 기록이 같다는 것은 형식·계보가 일치한다는 뜻이지, 인물·회사 동일성, 관계의 실질적 의미, 사실의 진위, 시간적 유효성이 모두 승인됐다는 뜻이 아니다. M4 시점의 개체가 약어·동명이인·간접 문맥인 경우는 별도로 살펴야 한다.

## 4. 변경 없이 확인할 사항과 수정 시 주의

1. **사람 이름과 법인:** `PERSON-RULE-...`과 `AUTO-...`는 잠정 정규화 이력이 있어 동일성의 추가 대조가 필요하다. 같은 이름만으로 새로운 병합을 확정하지 않는다.
2. **5홉의 시점:** 각 관계의 기사 발행일은 2024·2025·2026년 등으로 다르며 실제 관계의 기준일과 동일하지 않다. 다섯 관계가 한 시점에 동시 성립했다고 단정하지 않는다.
3. **코드·DB 수정 전:** M6는 매핑 결과의 `input_hash`를 사용하고 동일 입력 재적재 시 관계 속성을 갱신한다. 검증 주석을 추가할 때 원본 `sources_json`, 관계 ID와 의미 속성을 임의 수정하지 않고, 재적재 이후의 보존 여부를 실제 사용자 DB에서 확인해야 한다.
4. **재무 출처:** 두 수치는 KIND 게시 2025 사업보고서의 개별 재무제표와 대조했다. DART 직접 URL의 접근과 동일 문서 식별자 여부는 별도 확인이 필요하다.
5. **완료 상태:** 이 메모는 검토와 보완 제안이며, AuraDB 수정이나 수정 후 재조회가 이루어진 사례는 없다. 따라서 M8의 오류 보완 완료 증거로 이 메모만 제시할 수 없다.
