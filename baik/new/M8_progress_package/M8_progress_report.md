## 1. 검토 범위와 방법

M7에서 실제 반환된 경로 중 CQ02·CQ04·CQ05·CQ06·CQ07·CQ08·CQ10에 걸친 **원본 관계 기록 16건**을 선정했다. 추가로 사용자의 4.3 지분 관계 CSV에서 `56% 이상`과 `종류주 11.65%` 기록을 각 한 건씩 골라, 중복을 제외한 총 **18건**을 1차 검토했다. 다수 출처가 묶인 직접 관계는 이 표본에서 **선정한 원본 기록 1건**을 확인했으며 모든 출처를 전수 검증한 것은 아니다.

선정 기준은 공시·재무·뉴스와 서로 다른 관계 유형, 2홉·3홉·5홉 경로, 지분 수치·기준일 등 문제 가능성을 함께 살펴보는 것이었다. 이는 **의도적으로 고른 사례**이며 무작위·대표 표본이 아니다. 따라서 전체 추출 정확도나 성공률을 계산하지 않는다.

뉴스는 수집 기사 사본의 문자 위치와 M4 청크, 추출 관계, M5 기록, 사용자가 전달한 M7 조회 스냅샷을 구분해 대조했다. 공시는 보유한 보고서 HTML의 표 행과 주석, 추출 결과, M5, 사용자의 조회 결과를 확인했다. 이 문서 작성 중 현재 AuraDB를 새로 조회하거나 변경하지는 않았다.

> 인용이 원문 청크에 존재하고 단계 간 ID·속성이 이어진다는 확인은 **형식과 추적성 검증**이다. 모든 관계의 사실성, 정확한 시점 또는 개체 동일성이 승인됐다는 뜻이 아니다.

## 3. 발견한 실제 정규화 오류: 서로 다른 시상식의 오병합

### 3.1 무엇이 잘못됐나?

원래 서로 다른 기사에서 추출된 행사 개체의 표기가 모두 `시상식`이었고, 행사 날짜 속성은 비어 있었다. M5에서 **같은 행사명과 연도 미상**을 기준으로 잠정 병합하면서, 서로 다른 세 행사가 하나의 노드 `EVENT-RULE-c54dfcd323152a767b51`에 연결됐다.

| 원문에 나온 행사 | 원래 행사 언급 | 관련 원본 관계 기록 |
| --- | ---: | ---: |
| 2024 제주 그린어워드 시상식 | 2개 | 3건 |
| 2025 제주 그린어워드 시상식 | 1개 | 1건 |
| 한국광고학회 2026 올해의 브랜드상 시상식 | 7개 | 7건 |
| **합계** | **10개** | **11건** |

각 원문 청크에서 행사명과 장소 문맥을 확인했다. 2026년 부산 행사와 2024·2025년 제주 행사는 같은 행사가 아니다. [2024 기사](https://www.yna.co.kr/view/AKR20241122109500056?input=1195m), [2025 기사](http://www.jejumaeil.net/news/articleView.html?idxno=352069), [2026 기사](https://www.tournews21.com/news/articleView.html?idxno=147128).

**발생 단계와 원인:** M4가 기사마다 `시상식`이라는 일반 이름을 추출한 뒤, M5의 유연한 정규화 규칙이 이 이름의 연도 미상 항목을 같은 ID로 묶었다. 각 관계가 개별 원문에 나온다는 것과 여러 관계의 중간 행사가 같은 대상이라는 것은 다르다.

**영향 예시:** 2024 제주 시상식에 참여한 이니스프리 모음재단이, 오병합된 중간 행사 노드를 거쳐 2026 부산 시상식 장소와 연결되는 것처럼 보일 수 있다. 원문에 없는 경로를 그래프 연결만으로 만들어낼 위험이다.

### 3.2 준비한 보완

원본 M5 ZIP을 보존한 채, 위 노드 하나를 다음 세 노드로 나누는 **별도 교정본**을 만들었다.

- `EVENT-M8-2024-JEJU-GREEN-AWARDS`
- `EVENT-M8-2025-JEJU-GREEN-AWARDS`
- `EVENT-M8-2026-KAS-BRAND-AWARDS`

원래 행사 언급 10개와 원본 관계 기록 11건은 각각 원문 문맥에 맞는 행사 ID에 연결했다. 원본 기사 인용·관계 속성·출처 메타데이터는 그대로 보존한다. M6 매핑에서 기존 직접 관계 5개가 각 행사에 연결된 직접 관계 5개로 바뀐다.

| 항목 | 수정 전 | 교정본 예상 |
| --- | ---: | ---: |
| 노드 | 12,247개 | **12,249개** |
| 직접 관계 | 13,322개 | **13,322개** |
| 전체 원본 근거 기록 | 17,726건 | **17,726건** |

**실제 AuraDB에는 아직 반영하지 않았다.** 위 수치는 교정된 입력을 로컬에서 매핑한 예상 결과다.

### 3.3 로컬에서 확인한 것

- 원래 M5 ZIP과 교정본의 원본 관계 기록 ID 전체가 같고, 변경한 11건도 인용·수치·출처 메타데이터가 유지됨.
- M2 허용 유형·방향 검사 및 매핑 성공.
- 2024 제주 재단 → 오병합 `시상식` → 2026 부산 장소라는 잘못된 경로가 교정본의 로컬 그래프에서 사라짐.
- 코드를 모의 DB에 실행했을 때 수정 후 노드·관계·근거 수와 같은 코드의 두 번째 실행을 검사함.
- **실제 Neo4j Cypher 실행·트랜잭션과 AuraDB의 수정·재적재는 아직 시험하지 못함.**

## 4. 보완 전 사용자가 실행할 읽기 확인

제공된 `patch_m8.py`는 기본 실행 시 **읽기 확인만** 한다. AuraDB에서 현재 데이터셋 전체가 예상한 M6 입력과 일치하는지, 대상 노드에 다른 데이터셋의 관계나 예상 밖 속성이 붙어 있는지 확인한다.

```powershell
uv run .\patch_m8.py
```

정상적으로 `현재 데이터셋: 변경 전 상태`와 `읽기 확인만 했습니다`가 출력되면 결과를 전달한다. 그 후 별도 `--apply` 실행으로 변경할 수 있다. `--apply`는 실제 데이터에 영향을 주므로 기본 명령과 구분한다.

교정 시 대상 옛 행사 노드 한 개와 그에 딸린 다섯 관계를 세 노드와 다섯 관계로 대체하며, 사용자의 데이터셋에 한해 기존 M6 입력 지문을 교정본 지문으로 갱신한다. **다른 데이터셋은 갱신 대상이 아니다.** 이 지문 변경은 해당 데이터셋 전체 노드 12,249개와 관계 13,322개의 `input_hash` 속성 25,571개에 적용된다. 같은 데이터셋에 다른 적재·수정 작업을 동시에 실행하지 않는다. 오병합 관계의 변경 전 데이터는 실행 폴더에 백업하고, 교정본과의 전수 비교를 같은 트랜잭션에서 시도하도록 준비했다. 검사가 실패하면 자동 변경을 중단하도록 했지만, 실제 AuraDB에서의 실행 결과는 아직 확인되지 않았다.

수정이 성공한 이후에는 **교정본 M5 입력**을 사용하는 M6 코드로 확인해야 한다. 원래 M5 입력의 옛 M6 코드는 기존 오병합을 다시 만들 수 있으므로 사용하지 않는다. 새 지문이 반영되면 옛 입력의 M6 로더는 지문 불일치로 중단되도록 설계되어 있다.

## 5. 그 밖의 미해결 항목

- `COMPANY-COSRX`에서 출발하는 `OPERATES_BRAND` 관계는 기존 M6 입력에서 확인되지 않았다. 회사와 브랜드를 이름만으로 병합하거나 관계를 만들어 내지 않는다.
- `코스알엑스`, `COSRX`, `코스알엑스(COSRX)`는 서로 다른 브랜드 ID에 나뉘어 있어 원문을 근거로 별칭 통합 여부를 추가 검토할 수 있다.
- 지주회사 대표 ID와 기사에서 추출된 유사 회사 ID도 분리되어 있다. 관계 100여 건 이상에 영향을 줄 수 있으므로 근거·변경 이력·재적재 전략 없이 한꺼번에 병합하지 않는다.
- 기사 기반 지분율 93.2%와 공시 기준 90.3%는 기준일·계약·지분 산정 범위를 확인하기 전 한 값으로 통합하지 않는다.
- 지분 기준일과 주식 종류가 없는 뉴스 관계, 다른 시점의 관계가 합쳐진 5홉 해석은 추가 검토가 필요하다.

## 6. 현재 판정

**완료:** 의도적 표본 18건의 단계별 1차 대조, 공시·재무 원문 일부 대조, 시상식 오병합 발견, 보존 가능한 교정 입력과 로컬 모의 검증.

**미완료:** 사용자의 AuraDB에서 현재 상태 확인, 실제 오류 보완, 수정 후 원문–트리플–정규화–그래프 재대조와 실제 동일 입력 재실행 확인.

> 따라서 이 문서는 **M8 완료 보고서가 아니다.** 실제 보완과 재확인 결과가 확보된 뒤 기존 단계들과 같은 GitHub용 M8 완료 보고서를 작성한다.


검토한 2024년 연합뉴스 자료 한 건은 수집 텍스트가 기사 전체가 아닌 세 줄 요약으로 표시되어 있다. 이 사례의 원문 대조 범위는 확보한 요약문이다.
