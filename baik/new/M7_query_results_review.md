### CQ03: 공시 지분 관계 조회 결과

2026-03-31 기준일과 공시 출처 조건을 만족한 관계는 다음 6건이다. 수치는 **조회된 공시 표의 지분율**이며 지분율 기준·주석을 함께 확인해야 한다.

| 공시 표의 투자회사 | 대상 기업 | 표에 기록된 지분율 |
| --- | --- | ---: |
| 아모레퍼시픽홀딩스 | 아모레퍼시픽 | 38.1% |
| 아모레퍼시픽홀딩스 | 아모스프로페셔널 | 100.0% |
| 아모레퍼시픽홀딩스 | 에스쁘아 | 100.0% |
| 아모레퍼시픽홀딩스 | 에뛰드 | 100.0% |
| 아모레퍼시픽홀딩스 | 이니스프리 | 90.4% |
| 아모레퍼시픽홀딩스 | 퍼시픽테크 | 100.0% |

기준 자료는 [아모레퍼시픽홀딩스 2026년 1분기 보고서](https://kind.krx.co.kr/external/2026/05/15/001430/20260515003119/11013.htm)의 종속기업 현황 표와 해당 주석이다. 이 표의 기준일은 2026-03-31이며, 현재까지 지분 변동이 없었다는 의미는 아니다.

### CQ04: 2홉 예시

```text
아모레퍼시픽홀딩스 → 지분을 보유한다 → 아모레퍼시픽
                                      → 지분을 보유한다 → 코스알엑스
```

제공된 결과에서 두 관계의 기준일은 모두 **2026-03-31**로 조회되었다. 각 관계의 공시 표 지분율은 홀딩스→아모레퍼시픽 **38.1%**, 아모레퍼시픽→코스알엑스 **90.3%**다. 두 숫자는 각 관계의 원자료와 지분율 산정 기준을 확인해야 하며, 곱하거나 홀딩스의 코스알엑스 직접 지분율이라고 표시하지 않는다.

### CQ09: 4홉 결과가 없는 이유를 살펴볼 부분

CQ09는 **홀딩스 → 아모레퍼시픽 → 코스알엑스 → 브랜드 ← 제품** 경로를 조회하며, 코스알엑스는 대표 회사 ID `COMPANY-COSRX`로 지정했다. 이 조건에서 조회 결과는 0건이었다.

이번 M6 입력 데이터를 추가 확인했을 때, 해당 `COMPANY-COSRX`에서 출발하는 `OPERATES_BRAND` 관계가 없었다. 따라서 이 정확한 대표 ID를 사용하는 CQ09 경로가 이어지지 않는다. 이는 **코스알엑스에 브랜드가 없다는 뜻이 아니며**, 브랜드와 회사 정보가 다른 ID로 추출됐는지 또는 해당 관계가 추출·적재되지 않았는지 확인할 필요가 있다는 뜻이다. 이 추가 진단은 제공받은 M6 입력 파일 기준이며, AuraDB를 별도로 새로 조회한 결과는 아니다.

### CQ10: 5홉 후보와 시점 주의

첫 표본에는 다음과 같은 경로 후보가 있었다.

```text
서경배 → 아모레퍼시픽홀딩스 → 이니스프리 회사
       → 이니스프리 브랜드 → 팝업스토어 → 이니스프리 디아일 성수
```

이 경로는 다섯 관계가 그래프에서 연결된다는 **구조적 후보**다. 각 관계의 기사 발행일을 살펴보면 첫 표본에는 2024년·2025년·2026년 자료가 섞여 있다. 기사 발행일은 관계의 실제 발생일이나 지분 기준일과 같지 않으므로, 이 경로가 어느 특정 날짜에 모두 동시에 성립했다고 판단할 수 없다. 또한 일부 회사와 인물은 잠정 ID를 사용한다. M8에서 각 관계의 원문·시점·개체 동일성을 확인해야 한다.

## 4. AuraDB에서 시각화할 쿼리

아래 쿼리는 **Brian의 데이터셋만** 대상으로 한다. AuraDB의 그래프 화면에서 실행하면 `path`에 포함된 노드와 관계를 볼 수 있다. 반환된 관계를 선택하면 속성에서 `sources_json`, `source_count`, 필요 시 `disclosure_notes_json`을 확인할 수 있다. 시각화 쿼리는 아직 사용자의 AuraDB에서 별도로 실행한 결과가 아니다.

### 4.1 공시 지분 관계 2홉

```cypher
MATCH path = (holding:B_Company {entity_id:'COMPANY-AMOREPACIFIC-HOLDINGS'})
             -[r1:B_OWNS_STAKE]->
             (amore:B_Company {entity_id:'COMPANY-AMOREPACIFIC'})
             -[r2:B_OWNS_STAKE]->
             (cosrx:B_Company {entity_id:'COMPANY-COSRX'})
WHERE all(n IN nodes(path) WHERE n.dataset_id = 'brian_m6_20261108_v1')
  AND all(r IN relationships(path) WHERE r.dataset_id = 'brian_m6_20261108_v1')
  AND r1.as_of_date = '2026-03-31'
  AND r2.as_of_date = '2026-03-31'
  AND coalesce(r1.status, '') <> 'planned'
  AND coalesce(r2.status, '') <> 'planned'
RETURN path
LIMIT 10;
```

### 4.2 홀딩스→아모레퍼시픽→브랜드←제품 3홉

```cypher
MATCH path = (holding:B_Company {entity_id:'COMPANY-AMOREPACIFIC-HOLDINGS'})
             -[:B_OWNS_STAKE]->
             (amore:B_Company {entity_id:'COMPANY-AMOREPACIFIC'})
             -[:B_OPERATES_BRAND]->
             (brand:B_Brand {entity_id:'AUTO-0844f77d5fe95dfe45512c54'})
             <-[:B_PRODUCT_UNDER_BRAND]-
             (product:B_Product {entity_id:'PRODUCT-RULE-58c33d0e6bf0e5ae9f30'})
WHERE all(n IN nodes(path) WHERE n.dataset_id = 'brian_m6_20261108_v1')
  AND all(r IN relationships(path) WHERE r.dataset_id = 'brian_m6_20261108_v1')
RETURN path
LIMIT 10;
```

이 경로는 1차 조회 표본에서 나온 한율·제품 예시다. 화살표 방향은 **제품→브랜드**이므로 홀딩스에서 제품을 따라가며 볼 때 마지막 화살표를 거꾸로 탐색한다. 서로 다른 시점의 공시·기사 관계가 섞일 수 있다.

### 4.3 서경배에서 행사 장소까지 5홉

```cypher
MATCH path = (person:B_Person {entity_id:'PERSON-RULE-f6a2566b625c55579d14'})
             -[:B_OWNS_STAKE]->
             (holding:B_Company {entity_id:'AUTO-35e7396534ca88cbf4b974da'})
             -[:B_OWNS_STAKE]->
             (company:B_Company {entity_id:'AUTO-3d295451c1408042c9ad79cb'})
             -[:B_OPERATES_BRAND]->
             (brand:B_Brand {entity_id:'BRAND-INNISFREE'})
             -[:B_PARTICIPATES_IN]->
             (event:B_Event {entity_id:'EVENT-LOCAL-41d4094c93bfe76a380c'})
             -[:B_EVENT_IN_PLACE]->
             (place:B_Place {entity_id:'AUTO-02d895f9363095da99ca24d0'})
WHERE all(n IN nodes(path) WHERE n.dataset_id = 'brian_m6_20261108_v1')
  AND all(r IN relationships(path) WHERE r.dataset_id = 'brian_m6_20261108_v1')
RETURN path
LIMIT 10;
```

이 경로에는 잠정 정규화된 인물·회사와 시점이 다른 기사들이 포함된다. **5홉 조회가 가능하다는 시각화 사례**로 사용하고, 사실·기간 검토 전에는 확정 답변으로 제시하지 않는다.
