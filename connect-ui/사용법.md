# CONNECT 질문 테스트

1. 터미널에서 프로젝트 폴더로 이동하고 로컬 검색 서버를 실행합니다.

```bash
cd bulsae
uv run python -m bulsae.graphrag.web_server
```

2. https://connect-graphrag-test.dkssk136136.chatgpt.site 에 접속해 ChatGPT로 로그인합니다. 같은 컴퓨터에서 서버를 실행해야 합니다. 사이트가 로컬 서버에 연결되지 않으면 http://127.0.0.1:8769 에서도 같은 화면을 열 수 있습니다.
3. 질문을 입력하고 답변 및 근거 링크를 확인합니다. 종료할 때는 서버를 실행한 터미널에서 Ctrl+C를 누릅니다.

Neo4j와 OpenAI 접속 설정은 프로젝트의 기존 `.env`를 사용합니다. 질문에 따라 OpenAI API 사용량이 발생합니다. 그래프 검색은 읽기 전용이며 추출된 관계는 검토 전 후보일 수 있습니다.
