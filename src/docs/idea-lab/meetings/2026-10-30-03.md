# 제3차 과수 구상 재검토

날짜: 2026-10-30 · 상태: 독립 검토 및 교차 검토 완료 · 사용자 수요와 API 실응답 미검증

## 출발점

사용자 요청에 따라 [기존 구상과 인수인계](../../01_기존_구상과_인수인계.md)를 기준으로 세 에이전트가 과수 아이디어를 다시 검토했다. 세 역할 모두 `gpt-6.1-terra`를 사용했으며 문제 탐색·비판 검토는 high, 데이터 조사는 medium으로 실행했다. 기존 과수 구상의 최신 타깃은 가설이며, 인터뷰·API 실호출·기술자료 본문 검증은 아직 없다.

## 문제 탐색가의 제안

1. **상담 준비·사후 적용 보조:** 최근 관찰과 선택적 기록을 상담 질문 및 시간순 메모로 정리하고, 상담 후 적용 조건을 확인한다. 기록이 없는 경우 현재 알고 있는 사실만 입력하고 빈 항목은 미상으로 표시한다. 상담이 이미 충분하거나 정리 부담이 크면 필요성이 낮다.
2. **증상 구분·근거 확인:** 증상에 해당하는 가능한 범주와 추가 관찰 기준을 근거와 함께 확인하고, 관련성이 확인된 기록만 선택적으로 연결한다. 원인을 단정하지 않으며 기술자료 본문·적용 조건·권리 확보가 전제다.
3. **과거 작업·결과 비교:** 여러 시즌의 동일 구역 기록을 정렬해 차이를 찾는다. 기록의 차이는 원인 증명이 아니며, 기록이 불충분하면 단일 시즌 타임라인으로 축소한다. 단순 날짜·구역 필터가 충분할 수 있다.

세 후보의 사용자 문제 강도, 반복 빈도, 데이터 보유율과 구매자는 가설이다. 실제 최근 사례를 중심으로 기록이 있는 농가와 없는 농가를 함께 인터뷰하고 상담자도 별도로 확인한다.

## 데이터 조사자의 검토

2026-10-30 기준 공식 카탈로그·안내 확인이며 실응답, 본문, 필드별 품질과 실제 이용 가능성은 미검증이다.

## 비판적 검토와 교차 논의

비판적 검토자는 상담 준비와 상담 후 적용을 별도로 검증할 것을 권고했다. 상담 준비는 사용자 제공 관찰만으로 작게 시험할 수 있지만, 사후 적용은 상담 내용의 정확한 기록과 상담자의 확인 경로가 필요하고 잘못된 재해석의 위험이 크다. 상담자에게 요약을 확인하는 추가 업무가 생길 수 있으며 중요한 맥락이 빠질 수도 있다. 기존 수첩 사진이나 메모 공유로 충분할 가능성을 비교해야 한다.

증상 구분은 적절한 기술자료 본문·최신성·이용권을 확인하기 전 제품으로 약속하지 않는다. 병해충 자료는 상업적 이용금지가 표시되어 있으므로 권리 확인 전 상용 대상에서 제외한다. 다년 비교는 비교 가능한 기록과 반복 수요가 확인될 때 후순위로 시험한다.

문제 탐색가는 반론을 수용해 우선 가설을 **현재 관찰과 선택적 기록을 상담에 가져갈 수 있게 정리하는 보조**로 좁혔다. 기술자료가 없으면 자동 연결을 빼고 상담 메모만 시험한다. 자동 진단·처방은 하지 않는다. 필요한 정보는 사용자가 확인·수정하고 모르는 것은 미상으로 둔다.

## 다음 실험과 판단

- 최근 실제 상담 사례를 기록 유무가 다른 농가에서 동의하에 모집한다. 교육기관 추천만으로 모집하면 편향될 수 있으며 모집·인터뷰는 아직 진행하지 않았다.
- 기존 상담 준비 방식, 단순 시간순 메모·검색, 관계 탐색 시제품을 같은 사례로 비교한다. 농가와 상담자가 준비 시간, 빠진 맥락, 사실 오류, 입력 부담과 재사용 여부를 확인한다.
- 기술자료를 쓰는 실험에서는 사용 가능한 본문·작목·버전·조건을 먼저 확인한다. 그래프는 같은 자료와 질문을 사용하는 일반 검색·DB·RAG와 비교해 추가 효과를 살핀다.
- 상담이 이미 충분하거나 편익이 입력 부담보다 작으면 가설을 보류한다. 기술자료의 이용권·본문이 확보되지 않으면 해당 자료를 제외한다. 그래프의 추가 효과가 없으면 단순 정렬·검색 또는 일반 RAG로 전환한다.
