# 제7차 과수 재배일지 기반 관리 서비스 회의

날짜: 2026-10-30 · 네 역할 교차 검토 완료 · 사용자 수요·데이터 미검증

## 방향

사용자는 출하나 작업 인수보다 **재배일지를 기록하고 그 기록으로 재배 관리에 도움을 받는 서비스**를 원한다. 기존 과수 Graph RAG 구상과 이 방향을 기준으로 아이디어·시장·비판·데이터 네 역할이 논의했다. 실제 인터뷰와 API 실호출은 하지 않았다.

## 통합 가설: 관찰을 기록하고 변화와 다음 관리를 확인하는 재배일지

**과수 재배자가 구역별 이상 징후와 조치의 변화를 기억이나 흩어진 사진에 의존해 확인하기 어려운 문제를 해결하기 위해, 현장 관찰·조치를 간단히 기록하고 같은 구역의 경과와 관련 기술자료를 다시 볼 수 있게 하는 서비스.**

- 대상 가설: 직접 과원을 관리하며 증상 변화를 다시 확인하거나 상담하는 재배 책임자. 실제로 이런 사례가 얼마나 반복되고 기록을 재사용하는지는 미확인이다.
- 첫 사용의 계기: 이상 징후를 발견해 나중에 같은 구역의 변화를 비교하려는 순간. 과거 일지가 없어도 시작할 수 있다.
- 가상 흐름: 포도 B구역의 갈라진 열매를 발견해 구역·사진·한 줄 관찰을 기록한다. 날짜는 자동 제안하고 수정할 수 있다. 조치했다면 내용을 추가하고, 농가가 직접 정한 확인 계획이 있다면 연결한다. 다음에 같은 기록을 열어 사진과 관찰·조치의 시간순 변화를 보며 새 관찰을 추가하고 현장 확인이나 상담을 결정한다.
- 기대 가치: 사진과 일지를 다시 찾고 당시 상황을 설명하는 부담을 줄이고, 변화와 미확인 사항을 한곳에서 확인할 가능성이다. 실제 효과와 재사용은 가설이다.
- 자료 보조: 본문·이용조건·작목 적합성이 확인되고 전문가 검토를 받은 기술자료가 있다면 관련 관찰 기준과 적용 조건·출처를 제시한다. 없으면 자료 없음을 표시한다. 서비스는 원인·처방이나 적절한 재관찰 시점을 확정하지 않는다.
- 첫 기록만 있다면 비교 불가로 표시한다. 입력한 내용은 사용자가 확인·수정할 수 있고 기록 공백을 미실시로 해석하지 않는다.

## 세 후보와 교차 검토

1. **이번 주 작업판:** 농가가 정한 구역별 작업과 적용 조건, 마지막 수행 및 완료·보류를 연결한다. 시장 검증가는 기록 직후 보상이 명확하고 반복 사용을 관찰하기 쉽다고 보았으나 비판 검토자는 기존 일정·일지 앱이 충분할 수 있고 자동 추천의 적용 오류를 지적했다. 아이디어 탐색가는 농가가 정한 재확인을 관련 일지에 연결하는 후속 경험으로 수정했다.
2. **이상 징후 변화 추적:** 한 구역의 사진·관찰·조치를 시간순으로 남기고 변화를 확인한다. 기록이 없을 때도 시작할 수 있으나 사진첩·메신저 상담 대비 재관찰과 재사용이 실제로 일어나는지, 사진·구역 입력 부담이 크지 않은지 확인해야 한다. 사진만으로 진단하지 않는다.
3. **다음 생육기 회고:** 구역·시기별 과거 작업과 관찰을 보고 농가가 다음 계획의 확인 항목을 고른다. 작년 기록과 올해 생육·날씨 차이가 있으면 인과나 올해 처방을 확정하지 않는다. 다년 기록과 계절에 의존하므로 초기 필수가 아닌 후속 기능이다.

아이디어 탐색가는 세 개의 별도 앱보다 **관찰·조치 기록 → 농가가 정한 재확인 → 축적된 기록의 회고**로 연결하는 안을 제안했다. 이상 징후부터 시작하는 이유는 기록할 당장의 계기와 다시 볼 이유가 있다는 가설 때문이며, 실제 빈도와 효용이 확인되었다는 뜻은 아니다.

시장 검증가는 기록을 실제로 다시 찾는 농가, 의무·인증 등으로 작성하지만 재활용하지 않는 농가, 기록 없이 기억·상담에 의존하는 농가를 함께 조사하자고 했다. 과거 [농업ON 사업 안내](https://uni.agrix.go.kr/guide/lmxdata/2024_guide.pdf)에도 영농일지 기능이 안내되어 있어 기존 수첩·앱·사진첩과 직접 비교해야 한다. 현재 운영 상태와 사용률, 미충족 수요는 미확인이다.

## 데이터와 권리

- 일지·구역·사진·관찰·조치와 날짜는 농가가 제공한다. 개인 자료의 동의, 접근 권한, 삭제와 외부 모델 전송을 설계해야 한다. 과거 기록이 없어도 첫 관찰부터 시작한다.
- [작목별 농업기술정보](https://www.data.go.kr/data/3060743/openapi.do)는 공공 API 후보이나 실제 본문·작목별 범위·개별 이용권은 미검증이다. [병해충 검색](https://www.data.go.kr/data/15058504/openapi.do)은 포털에 상업적 이용금지로 표시되어 상용 활용 전 권리 확인이 필요하다.
- [농사로 OpenAPI](https://www.nongsaro.go.kr/portal/ps/psz/psza/contentMain.ps?menuId=PS00191)는 본인인증·신청·승인 후 키 발급을 안내한다. 공공데이터포털 키와 동일하다고 가정하지 않는다. API 실응답은 아직 없다.
- 기상 자료는 보조 맥락이며 개별 과원의 실제 미기후나 작업 기록을 대체하지 않는다. 기록의 선후 관계는 원인을 입증하지 않는다.

## 검증 계획

최근 실제 이상 관찰 사례가 있는 농가에게 기존 사진첩·수첩으로 당시 상태와 이후 경과를 찾게 하고, 같은 자료를 시간순으로 연결한 간단한 시제품과 비교한다. 첫 기록·수정 시간, 재열람·추가 관찰, 구역·날짜 오류, 다음 행동, 재사용과 부담을 관찰한다. 기록을 남기지 않는 농가도 모집하고 기존 상담·검색을 어떻게 이용하는지 확인한다. 적절한 본문과 권리를 확보하기 전 기술자료 자동 연결을 약속하지 않는다.

기록을 다시 볼 불편이 없거나 입력 부담이 편익보다 크고 기존 사진첩·앱으로 충분하다면 방향을 축소하거나 보류한다. Graph RAG는 같은 자료와 질문으로 날짜·구역 검색, 일반 RAG와 비교해 관계 정확성과 사용자 효용이 개선될 때만 채택한다.
