# 제4차 과수 서비스 사용자 가치·시장 검증 회의

날짜: 2026-10-30 · 상태: 네 역할 검토 및 교차 논의 완료 · 수요 미검증

## 진행

아이디어 탐색가의 역할을 사용자 가치 중심으로 보강하고, 시장 검증가를 추가했다. 아이디어·데이터·비판·시장 검증 네 역할이 `gpt-6.1-terra`로 참여했다. 동시 실행 제한으로 나누어 실행했고 결과를 서로 전달했다. 기존 [과수 인수인계](../../01_기존_구상과_인수인계.md)와 [3차 회의](2026-10-30-03.md)를 출발점으로 삼았다. 아래 사용 장면과 기대 효과는 가상 예시 및 가설이다.

## 아이디어와 사용자 가치

### 1. 관찰의 다음 확인점

과수 운영자가 낯선 증상을 봤을 때, 어떤 부분을 더 관찰해야 할지 구체적인 기준과 근거를 찾는다. 예를 들어 잎 색 변화의 발생 부위·시점 등을 입력하면 확보된 작목별 자료의 관찰 기준과 적용 조건을 보고 다음 확인을 선택한다. 기록은 선택이며 모르는 정보는 미상으로 둔다. 기대 가치는 필요한 관찰을 놓치지 않는 것이다. 자료가 없으면 기준을 지어내지 않으며 원인이나 처방을 확정하지 않는다.

사용자는 최근 실제 문제를 겪고 검색이나 상담으로 충분한 답을 얻지 못한 농가일 수 있지만, 빈도·미충족 수요·재사용은 미확인이다. 기록·기술자료 연결의 이점도 검증 전 가설이다.

### 2. 내 과원의 변화 돌아보기

과원 운영자가 같은 구역의 과거와 현재 상황이 달라 보일 때, 동의해 제공한 기존 수첩·사진·일지에서 같은 구역과 시기의 기록을 나란히 찾는다. 예를 들어 올해와 작년 착색 관련 관찰과 작업 기록, 공백 기간을 본다. 기대 가치는 흩어진 기록을 다시 찾는 부담 감소다. 기록 공백은 작업 미실시가 아니며 기록 차이가 원인임을 뜻하지 않는다. 기록이 없으면 현재 관찰의 단일 시간순 정리로 축소한다.

같은 구역의 비교 가능한 다년 기록을 보유하고 이를 실제로 다시 찾는 농가가 대상일 수 있으나, 보유율과 반복 수요는 미확인이다. 수첩·사진·스프레드시트의 날짜/구역 검색이 비교 기준이다.

### 3. 교육 내용 다시 찾기

교육을 받은 과수 운영자가 작업 전 적용 조건이 기억나지 않을 때, 사용 권한이 있는 교육자료의 해당 구절·페이지·시점과 조건을 찾는다. 기대 가치는 강의자료와 메모를 다시 찾는 부담 감소다. 자료에 없는 조건은 미상이며 결과가 농가별 적용 승인이나 처방은 아니다. 자료가 없거나 이용 권한을 확인할 수 없으면 기능을 보류한다.

최근 교육자료를 실제로 다시 찾는 농가가 대상일 수 있지만 빈도와 기존 PDF 검색·교육자 문의 대비 가치는 미확인이다. 업로드 가능 여부와 외부 모델 전송 동의는 별도로 확인해야 한다.

## 시장 검증가: 기존 대안과 사용자 가설

- [국가농작물병해충관리시스템 모바일 안내](https://ncpms.rda.go.kr/npms/MobileInfo.np)는 병해충 검색·자가진단, 등록 농장 작목별 예측, 회원 전문가 진단의뢰를 안내한다. [AI 병해충 영상진단 안내](https://ncpms.rda.go.kr/npms/dgnss/ai/Guide.np)도 존재한다. 이는 강한 기존 대안의 증거이나 실제 이용 빈도나 미충족 수요의 증거는 아니다. 개인 일지 연결·다년 비교·교육자료 검색의 실제 지원 범위는 별도 확인이 필요하다.
- [농진청ON](https://rda.go.kr/rdaOn/rdaOnMain.do)은 교육과 상담을 안내한다. 상담의 접근성, 효과와 남는 불편은 현장 사례로 확인해야 한다.
- 2024년 귀농·귀촌 실태조사에 따르면 귀농 준비기간의 교육 이수율은 30대 이하 68.6%, 60대 39.0%다. 이는 귀농가구 조사이며 과수 서비스의 사용자 규모나 수요를 뜻하지 않는다. 이전 인수인계의 조사연도 오기를 [농식품부 발표](https://www.mafra.go.kr/bbs/home/792/573439/artclView.do)에 맞춰 정정했다.
- 실제 이용자, 구매자·도입 결정자, 자료 제공자는 다를 수 있다. 누구인지와 비용 부담 의사는 확인되지 않았다.

## 교차 검토

데이터 조사자는 ①에 작목·생육단계·관찰 기준이 포함된 본문과 적용 조건, 최신성·권리 확인이 필요하다고 밝혔다. 병해충 API는 상업적 이용금지 표시가 있다. ②는 동일 구역·시즌·단위의 비교 가능성과 일지 접근 동의가, ③은 실제 문서의 원문·개정·조건과 외부 처리 권리가 필요하다. 세 후보 모두 API 실응답과 사용자 자료 표본은 아직 확인하지 않았다.

비판적 검토자는 ①의 직관적 가치를 인정하면서도 NCPMS·상담과 같은 사례로 비교하지 않고 차별성을 주장할 수 없다고 했다. ②는 날짜 필터, ③은 PDF 검색·강사 문의가 강한 기준선이다. 사용자가 입력·업로드·검토에 들이는 비용도 비교해야 한다. NCPMS에서 개인 이력과 교육자료를 다룰 수 없는지 현재 확인되지 않았으므로 기능 부재를 주장하지 않는다.

아이디어 탐색가는 이 반론을 수용해 ①의 고유 가치를 가정하지 않고, ②는 기록 원문·비교 가능성, ③은 자료 권리·출처를 먼저 확인하자고 수정했다. ②→③→①의 작은 실험 순서는 예상 자료·검증 부담을 기준으로 한 제안일 뿐 사용자 가치의 순위가 아니다. 실제 문제 빈도가 높고 적법한 자료와 전문가가 확보되면 ①을 앞당길 수 있다.

## 수요 검증 계획과 중단 조건

1. 한 작목의 최근 실제 사례를 가진 농가와 상담자를 여러 경로로 모집한다. 교육 참여·비참여, 기록 보유·미보유, 지역과 경력 차이를 포함하고 모집 거절과 편향을 기록한다. 아직 인터뷰하지 않았다.
2. 최근 사건을 먼저 회상하고 사용했던 수첩·검색·NCPMS·상담과 결과를 확인한다. 증상 사례, 기록 재탐색 사례, 교육자료 재탐색 사례를 구분한다.
3. 동의한 같은 자료와 질문으로 기존 방식, 검색·필터, 제안 경험을 비교한다. 농가의 확인 성공과 입력 부담·재사용을 관찰하고, 증상 관찰 기준의 누락과 오류는 작목 전문가가 검토한다.
4. 기존 방식으로 충분하거나 실제로 반복하지 않는 문제, 자료·권리·전문가 확보가 불가능한 후보는 축소하거나 보류한다. Graph RAG는 같은 자료의 검색·DB·일반 RAG보다 의미 있는 추가 효과가 있을 때만 채택한다.

편의 표본 인터뷰 결과는 전체 농가 규모나 시장 크기로 일반화하지 않는다. 시장 규모·구매 의사·서비스 수요는 현재 미확인이다.
