# 제6차 과수 서비스 타깃·가치 구체화 회의

날짜: 2026-10-30 · 네 역할 교차 검토 완료 · 모든 수요와 효과는 미검증 가설

## 회의 목적

기존 인수인계의 과수·기록·기술자료 맥락을 유지하면서, 단순한 문서 요약을 넘어 특정 사용자가 특정 순간에 얻는 결과가 다른 서비스 후보를 만들었다. 아이디어·시장·비판·데이터 역할이 Terra로 참여해 독립 제안과 교차 검토를 진행했다.

## 후보 1. 교대 작업의 인수 확인

**여러 작업자가 서로 다른 시간에 같은 구역을 이어 맡는 과수원에서, 완료 범위나 보류 사유가 전달되지 않아 작업이 누락되거나 반복되는 문제를 해결하기 위해, 지시부터 수행·예외·다음 작업자의 인수 확인까지 이어주는 서비스.**

- 대상: 과원 책임자와 교대 작업자. 실제 교대 빈도, 기기 접근성과 구매자는 미확인.
- 가상 장면: A구역 적과를 하다 비로 일부만 마쳤을 때 완료 범위와 중단 이유를 남기고, 다음 작업자가 남은 일과 예외를 보고 인수를 확인한다.
- 가치 가설: 단순 메모가 아니라 예외가 다음 사람에게 전달됐는지 확인하고 재질문·누락을 줄인다. 기록이 없으면 오늘 작업부터 시작한다. 기술자료는 책임자가 필요할 때 조건을 확인하는 선택 기능이다.
- 대안과 검증: 구두·전화·메신저·종이 인수장·공유 체크리스트가 강한 대안이다. 최근 실제 교대 사례에서 예외 누락, 재질문, 입력·인수 시간 및 자발적 재사용을 비교한다. 기존 방식이 충분하거나 입력이 부담이면 보류한다. 일정 DB가 충분할 수 있어 Graph RAG는 전제하지 않는다.
- 데이터: 구역 ID, 작업 지시, 담당자, 완료 범위·시각 및 예외는 농가·작업자 제공이 필요하다. 미응답을 완료로 취급하지 않고 권한과 동의를 확인한다.

## 후보 2. 혼합 출하 로트 역추적

**여러 구역의 수확물을 섞거나 한 수확물을 여러 출하 건으로 나누는 과수 출하 책임자가 품질 이의를 받았을 때 관련 생산·선별 범위를 찾기 위해, 출하 건부터 혼합·분할 로트와 구역까지 확인 가능한 연결과 원자료를 되짚는 서비스.**

- 대상: 혼합·분할 출하를 담당하며 실제 이의 사례를 겪는 농가 또는 출하 조직. 사례 빈도·기록 보유·자료 제공 의사는 미확인.
- 가상 장면: 두 구역의 과일을 한 선별 로트에 합쳐 두 거래처에 나눈 뒤 한 거래처가 품질 이의를 제기하면, 같은 로트의 다른 출하와 관련 가능 구역을 근거와 함께 확인한다. 어느 구역이 원인인지 또는 누가 책임자인지는 단정하지 않는다.
- 가치 가설: 사진만 모으는 것이 아니라 실제 혼합·분할 관계를 따라 확인 가능한 범위와 끊어진 연결을 보여줘 사실관계를 정리한다. 연결 자료가 없으면 미상으로 두며 역추적 결과를 약속하지 않는다.
- 대안과 검증: 엑셀 출하대장, 선별장 자료, 수첩과 사진 수동 검색. 이의가 드물거나 관계가 이미 쉽게 확인되면 불필요하다. 먼저 실제 사례와 동의받은 로트 연결기록이 있는지 확인하고 기존 방법·관계표/DB와 연결 정확도, 공백, 시간·입력 부담을 비교한다. 자료나 사건이 없으면 보류한다.
- 데이터: 출하번호·일자, 선별/수확 로트의 혼합·분할·구역 관계, 전표·사진은 농가·출하 조직·거래처가 제공해야 하며 공유 권한이 필요하다. 시간만 일치한다고 같은 로트로 확정하지 않는다. 기술자료는 품질 현상 확인 기준의 참고자료다.
- 기술 판단: 여러 단계의 관계가 실제 존재하면 Graph RAG를 시험할 수 있으나 같은 자료의 DB 조인보다 유용한지는 미검증이다.

## 후보 3. 생육단계별 저온 예보 대응 점검

**저온 예보를 본 뒤 여러 생육단계의 사과 구역 중 어디의 준비 상태를 먼저 확인할지 어려운 과원 책임자를 위해, 예보와 구역 상태, 해당 조건의 기술 근거를 함께 보여 현장 확인을 돕는 서비스.**

- 대상: 저온 경보에 대응하며 서로 다른 생육단계의 사과 구역을 관리하는 책임자. 실제 어려움과 반복성은 미확인.
- 가상 장면: 농가가 구역과 생육단계를 고르면 그 조건에 맞는 전문가 검토 자료 구절과 이전 설비 점검 기록을 본 뒤 현장 온도·설비를 확인하거나 지도기관에 문의한다.
- 가치 가설: 일반 날씨 알림 다음에 특정 구역의 준비 상태를 확인한다. 예보는 개별 과원의 실측이 아니며 피해·처방을 확정하지 않는다. 기록이 없으면 현재 상태를 확인해 입력하고 이전 점검은 미상으로 둔다. 조건에 맞는 자료와 권리가 없으면 범용 알림으로 축소하지 않고 보류한다.
- 대안과 검증: 기상 알림·농업기술센터 공지·기존 점검표·상담. 실제 과거 예보와 구역 사례로 확인 누락·불필요 경고·입력 부담을 비교하고 작목 전문가가 자료 적용 오류를 평가한다.
- 데이터: [기상청 단기예보](https://www.data.go.kr/data/15084084/openapi.do)는 카탈로그상 격자 예보로 과원별 미기후 실측이 아니다. 구역·품종·생육단계·시설 기록은 농가가 제공해야 한다. [작목별 농업기술정보](https://www.data.go.kr/data/3060743/openapi.do)의 실제 본문·작목별 범위·이용 조건은 미검증이며 [병해충 검색](https://www.data.go.kr/data/15058504/openapi.do)은 상업적 이용금지 표시가 있다. 실제 API 실호출은 하지 않았다.

## 시장·비판·데이터 교차 검토

시장 검증가는 ① 책임자와 작업자를 짝으로, ② 최근 실제 출하 이의 사례의 농가와 출하 담당자를, ③ 최근 저온 대응 사례의 농가와 지도자를 각각 모집하자고 했다. 연령보다 실제 사건과 기존 행동을 기준으로 나누며 구매자·도입자·자료 소유자는 별도 확인한다. 기존 방식이 충분하거나 추가 입력을 거부하면 보류한다.

비판적 검토자는 핵심 가치를 보존할 것을 강조했다. ①은 지시→수행·예외→인수 확인, ②는 혼합·분할 관계의 역추적, ③은 구역·생육단계에 맞는 점검 근거가 빠지면 각각 기존 도구와 차별성이 약해진다. 안전·자료 연결 오류를 방지하기 위해 원문·시점·확인 상태를 남긴다.

데이터 조사자는 세 후보의 개인 구역 기록·작업 이력·출하 로트 관계를 공공데이터가 대체하지 못한다고 밝혔다. 기상 예보와 기술정보는 후보 ③의 보조 자료이나 카탈로그 확인 수준이다. API 실응답과 자료 본문·권리·누락률은 확인하지 않았다.

아이디어 탐색가는 세 후보를 교대 작업의 인수 확인, 혼합 로트 역추적, 사과 저온 점검으로 좁히고 위의 반론을 반영했다. 잠정적으로 ①은 실제 인수 사례와 종이/간단 DB로 문제를 작게 시험하고, ②는 동시에 최근 이의 사례와 로트 연결 기록을 먼저 찾으며, ③은 본문·권리·전문가 확인을 선행하자고 제안했다. 이는 검증 접근성에 따른 제안이며 시장성 순위가 아니다.
