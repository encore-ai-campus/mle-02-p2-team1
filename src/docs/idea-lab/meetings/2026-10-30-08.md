# 제8차 재배일지·기술문서 결합 아이디어 검토

날짜: 2026-10-30 · 네 역할 검토 완료 · 사용자 인터뷰·API 실호출·실험 미진행

## 검토 대상

진행자가 제안한 네 후보를 아이디어·시장·비판·데이터 역할이 독립 검토했다. 이전에 사용자에게 제시한 네 아이디어 자체는 진행자가 작성했으며, 해당 답변 시점에 네 에이전트가 새로 검토한 것은 아니었다. 이번 문서가 네 역할의 후속 검토다.

1. **내 과원에 맞는 작업 조건 확인:** 예정된 작업에 대해 구역의 생육·작업 기록과 기술문서의 적용 조건을 대조한다. 기록이 없으면 현재 작업과 조건부터 입력한다.
2. **작업 전 놓친 확인사항 점검:** 관수 등 작업을 하기 전 기술문서상 확인할 사항과 기록에서 확인되지 않은 사항을 보여준다. 미기록은 미실시가 아니다.
3. **문제가 생긴 구역의 관리 과정 되짚기:** 증상 관련 문서의 구분 기준을 살피고 같은 구역의 관찰·조치 경과와 추가 확인사항을 함께 본다. 증상만으로 관수·시비를 원인으로 가정하지 않는다.
4. **지난해 기록을 다음 생육기 계획에 반영:** 구역별 지난해 작업·관찰과 올해 상태, 기술문서 적용 조건을 대조해 농가가 확인할 계획을 선택한다. 과거 기록이 없다면 비교가 불가능하다.

## 역할별 검토

**아이디어 탐색가:** 1과 2는 각각 적용 조건 대조와 미확인 항목 표시라는 차이가 있지만, 하나의 작업 전 화면으로 묶는 편이 자연스러울 수 있다. 기록상 확인·농가 확인 필요·자료 없음으로 나누고 농가가 결정한다. 3은 문제가 생긴 뒤, 4는 다음 시즌이라는 다른 사용 순간이다. 각 흐름 모두 실제 수요와 이용 의사는 미검증이다.

**시장 검증가:** 1은 특정 작업을 어떻게 실시·보류할지 조건을 확인하는 순간이고, 2는 작업 전에 무엇을 아직 확인하지 않았는지 찾는 순간이라는 구분을 제시했다. 두 불편이 실제로 구분되는지는 최근 실제 사례로 확인해야 한다. 기록 재사용 농가, 의무로 기록하지만 다시 보지 않는 농가, 기록 없는 농가와 상담 이용/미이용자를 포함한다. 구매자와 도입 주체는 미확인이다.

**비판적 검토자:** 1과 2의 중복이 커 먼저 같은 사례로 비교하고 추가 가치가 없으면 합치자고 제안했다. 조건이 빠진 체크리스트를 완전하다고 오해하면 위험하다. 3은 문서의 증상 구분 기준과 필요한 질문을 먼저 살펴보고 관련 기록을 연결해야 한다. 4는 다년 기록과 계절 의존성이 크고 연도별 차이를 인과나 처방으로 만들면 안 된다. 같은 자료로 검색/DB, 일반 RAG, Graph RAG를 비교해야 한다.

**데이터 조사자:** 네 후보 모두 농가의 구역·작물·날짜·관찰/작업 기록이 핵심이다. 공공자료가 실제 관수·토양수분·과거 작업을 대체하지 못한다. 1은 현재 작업·상태, 2는 실제 관수 및 토양 상태 등, 3은 관찰·사진·조치, 4는 작년·올해의 비교 가능한 기록이 필요하다. 기록이 없는 항목은 미상이며 4는 과거 비교가 불가능하다.

## 공개 자료 확인 상태

- [작목별 농업기술정보](https://www.data.go.kr/data/3060743/openapi.do): LINK/XML, 카탈로그상 이용허락범위 제한 없음·자동승인. 실제 본문·작목별 범위·개별 자료 권리 미확인.
- [작물 병해충 검색](https://www.data.go.kr/data/15058504/openapi.do): 카탈로그에 출처표시·상업적 이용금지 표시. 실제 응답·본문 및 상용 별도 허락 미확인.
- [농사로 OpenAPI 신청 안내](https://www.nongsaro.go.kr/portal/ps/psz/psza/contentMain.ps?menuId=PS00191): 본인인증·신청·승인 후 키 발급 안내. 포털 키와 같다고 가정하지 않는다.
- [기상청 단기예보](https://www.data.go.kr/data/15084084/openapi.do)와 [과수 휴면타파](https://www.data.go.kr/data/15168306/openapi.do)는 참고 예보·예측이며 과원 실측이나 실제 작업의 대체자료가 아니다.

위는 카탈로그 확인 수준으로, API 실호출·응답 샘플·작목별 본문·실제 농가 자료의 품질은 검증하지 않았다.

## 다음 판단

1과 2는 대시보드에서 별도 후보로 유지하되 하나로 통합할 가능성을 명시한다. 한 작목의 최근 실제 작업과 증상 사례를 동의하에 모집해 기존 수첩·검색·상담과 비교하고, 확인 누락·잘못된 안심·입력 부담·재사용을 관찰한다. 4는 자료와 생육기 의존성이 크다. 기술자료가 확보되지 않거나 기존 방식으로 충분하면 축소·보류하며, Graph RAG는 동등한 자료와 질문으로 일반 검색/RAG보다 의미 있는 추가 효과를 확인해야 한다.
