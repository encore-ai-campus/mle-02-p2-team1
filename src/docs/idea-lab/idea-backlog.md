# 아이디어 대장

기준일: 2026-10-30. 우선순위는 1차 회의의 가설이며 수요·데이터 실응답 검증 전이다.

| 후보 | 상태 | 핵심 불확실성 |
|---|---|---|
| 지원사업 공고 근거 비교 | 우선 조사 | 공고 본문·변경 이력과 기존 포털 대비 가치 |
| 지역 공사 영향 탐색 | 우선 조사 | 공사와 통제의 공간·시간 연결 및 갱신 |
| 법령·행정자료 변경 추적 | 추가 검토 | 사용자 업무, 개정 관계 제공 범위, 기존 도구 대비 가치 |
| 식품 회수 연관 추적 | 조건부 보류 | 제품 식별·공급 관계 데이터 확보와 최신성 |
| 시설 접근성 탐색 | 보류 | 출입구·고장 정보의 정확성 및 현장 갱신 |
| 공연 협업 탐색 | 추가 조사 후보 | 출연자 연결 범위와 실제 수요 |

세부 제안과 이견은 [1차 회의록](meetings/2026-10-30-01.md)을 참조한다.

## 제2차 회의 갱신 — 2026-10-30

| 후보 | 잠정 판단 | 핵심 확인 사항 |
|---|---|---|
| 공개 소프트웨어 이슈·릴리스 근거 탐색 | 우선 실사 제안 | 명시적 이슈→PR→릴리스 연결과 이용 조건, 유지보수자·운영자 수요 |
| 제조 설비 부품 변경 영향 | 보류 | 비공개 BOM·승인 이력과 현장 전문가 접근 |
| 연구실 실험 재현·변경 이력 | 보류 | 실행별 내부 기록과 연결 식별자, 전문가 접근 |

지원사업 공고 비교와 지역 공사·통제 영향은 계속 우선 실사 제안이다. 2차 검토의 순위는 데이터·사용자 검증 전 가설이다. [2차 회의록](meetings/2026-10-30-02.md)

## 제3차 회의 — 기존 과수 구상 재검토

| 후보 | 잠정 판단 | 핵심 확인 사항 |
|---|---|---|
| 과수 상담 준비 보조 | 우선 검증 가설 | 상담 전 정리의 실제 불편과 입력 부담, 상담자의 수용 |
| 상담 후 적용 보조 | 별도 후속 가설 | 상담 내용 기록의 정확성과 상담자 확인 경로 |
| 증상 구분·근거 탐색 | 자료 확인 후 검토 | 작목별 본문·최신성·이용권, 추가 관찰의 적절성 |
| 다년 작업·결과 비교 | 후순위 | 비교 가능한 동의 기록과 반복 수요, 단순 필터 대비 가치 |

[3차 회의록](meetings/2026-10-30-03.md). 기존 문서 기반의 재검토이며 실제 사용자 수요와 API 응답은 미검증이다.

## 제4차 회의 — 사용자 가치와 시장 검증

관찰의 다음 확인점, 내 과원의 변화 돌아보기, 교육 내용 다시 찾기를 제안했다. 사용자 수요와 차별성은 미검증이며 NCPMS의 병해충 검색·자가진단·전문가 의뢰가 기존 대안이다. 구체적인 사용 장면, 비교 기준과 자료 조건은 [4차 회의록](meetings/2026-10-30-04.md)을 참조한다.

## 제5차 회의 — 문제를 해결하는 서비스 후보

거래처별 출하 준비, 공동작업 일정 조율, 재해 신고 준비를 각각 사용자 문제와 서비스 흐름으로 제안했다. 시장 수요와 효과는 미검증이고 공동작업은 Graph RAG가 불필요할 수 있다. [5차 회의록](meetings/2026-10-30-05.md)
